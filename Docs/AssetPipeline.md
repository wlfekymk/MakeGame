# 3D 에셋 파이프라인 계약 (v1 — 2026-08-17)

이 문서는 **에셋을 만드는 쪽과 게임에 붙이는 쪽 사이의 계약**이다.
여기 적힌 규격을 어긴 에셋은 배포하지 않는다. 규격이 바뀌면 이 문서를 먼저 고친다.

관련 문서: `Docs/AGENT_BRIEF.md`(프로젝트 전반 필독) — 이 문서는 그 하위 규격이다.

---

## 0. 왜 계약이 필요한가

곰 모델(v0.01.120)을 붙이면서 실제로 겪은 것들이다. 전부 계약이 없어서 났다.

- 원본이 **2미터 정규화 박스**로 들어와서 실제 크기를 알 수 없었다 → 길이를 코드 상수에 맞춰 구워야 했다.
- 원본 축이 **Z-up**이었다 → 런타임 회전으로 맞추려 하면 비균등 부모 스케일과 곱해져 전단이 난다.
- 원점이 **바운딩 박스 중심**이었다 → 발이 땅에 안 붙는다.
- 히트박스가 모델보다 **58cm 높았다** → 콜라이더와 보이는 몸이 어긋났다.
- Unity OBJ 임포터의 **Convert Units가 켜져 있었다** → 끄지 않으면 배율이 어긋날 수 있다.

## 1. 좌표·단위 (가장 중요)

| 항목 | 규격 |
|---|---|
| 단위 | **미터**. Unity Scale Factor 1, **Convert Units 반드시 끔** |
| 위 | **+Y** |
| 정면 | **+Z** (생물의 주둥이·기계의 앞면이 향하는 쪽) |
| 오른쪽 | +X |
| 원점 | **접지 중심.** 밑면이 정확히 y = 0이고, X/Z 원점은 **지면에 닿는 부분의 중심**이다 |
| 회전 | **정점에 구워서 내보낸다.** 런타임에 자식 회전으로 축을 맞추지 마라 |

> **원점이 왜 '바운딩 박스 중심'이 아닌가**: 휜 야자수는 크라운이 bbox를 지배해서
> bbox 중심을 쓰면 **줄기 밑동이 원점에서 0.74m까지 밀려난다**(실측). 그러면 스폰 지점에
> 나무가 서지 않고 배치 코드가 물체마다 보정값을 들고 있어야 한다.
> 대칭 물체(바위 등)는 두 기준이 같으므로 `mgbuild`의 `align="bbox"`를 그대로 써도 된다.
> 조립체(줄기+잎처럼 비대칭)는 `align="ground"`가 기본이다.

> **전단 경고**: 이 프로젝트의 위험 요소 루트는 `localScale`이 비균등이다.
> 비균등 부모 스케일 × 자식 회전 = 전단이다. 곰이 z축 0.39배로 찌부러졌던 사고의 원인이다.
> 자식 `localRotation`은 **항상 identity**로 두고, 필요한 기울기는 메시에 구워라.

## 2. 삼각형 예산

| 분류 | 상한 | 예 |
|---|---|---|
| 소품 (small prop) | **1,500** | 돌조각, 부싯돌, 코코넛, 도구 |
| 중형 소품 | **4,000** | 바위, 대나무 다발, 모닥불, 보관 상자 |
| 대형 구조물 | **8,000** | 야자수, 뗏목 부품, 작업대 |
| 생물 | **12,000** | 곰 성체(실측 12,000) |
| 히어로 | **20,000** | 비행기 잔해 등 섬당 1개짜리 |

섬 하나에 같은 종류가 여러 개 깔린다. **개수 × 삼각형**으로 생각해라.
상한을 넘겨야 할 근거가 있으면 그 수치와 이유를 보고하고 계약을 고친다.

## 3. 파일 형식과 경로

- 메시는 **OBJ**. Unity가 기본 임포터로 읽고, `.mtl` 없이도 문제없다.
  - 정점 법선(`vn`) **반드시 포함**. UV(`vt`)는 텍스처를 쓰면 필수.
  - 사각형 금지, **삼각형만**.
- 경로
  - 메시: `Assets/_Project/Resources/Models/<이름>.obj`
  - 텍스처: `Assets/_Project/Resources/Textures/<이름>_albedo.png`, `<이름>_normal.png`
- 로드: `Resources.Load<GameObject>("Models/<이름>")` — **확장자를 붙이면 항상 null이다.**

### 텍스처
- PNG, 2의 거듭제곱. 소품·중형 **1024²**, 생물 **1024²**, 히어로만 2048².
- 알베도는 sRGB(기본값). **노말맵은 `.meta`에 `textureType: 1`이 필요**하고, 이건 디렉터가 써 준다.
- **roughness·metallic 맵은 넣지 마라.** 곰에서 확인했듯 생성 도구가 뱉는 값은 노이즈였다.
  거칠기는 코드에서 상수로 준다(털 0.17 등).

## 4. 머티리얼과 콜라이더는 에셋이 아니라 코드다

- **Unity 머티리얼 에셋을 만들지 마라.** 런타임에 코드가 URP Lit을 만들어 텍스처를 물린다.
  - 셰이더 탐색은 `StructureVisualBuilder.CreateColorMaterial`과 **같은 방식**을 쓴다.
  - 런타임 머티리얼 이름은 반드시 `StructureVisualBuilder.RuntimeMaterialPrefix`(`"MG~"`)로 시작한다.
    이 접두사가 없는 머티리얼을 `Destroy`하면 Unity 내장 에셋을 파괴해 에러가 쏟아진다(실제 사고).
  - 같은 텍스처를 쓰는 에셋은 머티리얼을 **한 장만 만들어 공유**한다(SRP 배처가 갈리지 않게).
- **임포트 시 Generate Colliders는 끈다.** 콜라이더는 코드에서 프리미티브로 만든다.
  게임플레이(채집 조준, 피격 판정, 계단 통행)가 정확한 치수에 걸려 있어서
  메시 콜라이더에 맡기면 조용히 어긋난다. 야자잎 콜라이더가 보이는 크기의 1/10이던 사고가 그 예다.
- **콜라이더 치수는 모델 실측에서 나온다.** 모델을 바꾸면 콜라이더 상수도 같이 바꾼다.
  곰 히트박스가 58cm 어긋났던 게 이걸 안 지켜서다.

## 5. 만드는 방법

### 사물은 스크립트로
`Tools/blender/` 아래 **파이썬 스크립트**로 만든다. `.blend` 바이너리를 최종 산출물로 두지 마라 —
diff가 안 되고, 에이전트가 읽지도 고치지도 못하고, "5cm만 길게"가 사람 작업이 된다.

- 헤드리스 Blender(`bpy`)는 클라우드 컨테이너에 설치돼 있다(5.0.1). Blender GUI가 필요 없다.
- **난수는 반드시 시드를 고정**하고 시드를 스크립트에 적는다. 같은 스크립트는 같은 메시를 낸다.
- 변종은 메시를 여러 개 만들지 말고 **한 메시 + 인스턴스별 스케일/회전 지터 + 색 틴트**로 낸다.
  드로우콜과 용량이 같이 늘어나는 것을 막는다.

### 생물은 외부에서
유기적 형태는 생성 도구(Meshy 등)나 손 모델링이 낫다. 사용자가 넘겨주면
**감면 → 축 정리 → 원점 정렬 → 검수 → 연결**을 이쪽이 맡는다.
감면은 UV를 보존하는 방식을 쓴다(`pymeshlab`의 texture 보존 QEC).

## 6. 검수 — 렌더 없이 배포 금지

모든 에셋은 **턴테이블 렌더 PNG**를 같이 낸다. 디렉터가 눈으로 보고 통과시킨 것만 배포한다.

- 4방향(정면·측면·후면·3/4) + 바닥 기준선이 보이게.
- 확인 항목: 발/밑면이 y=0에 붙어 있는가 · 정면이 +Z인가 · 찌그러짐이 없는가 · 크기가 맞는가.
- 렌더는 저장소에 넣지 않는다(용량). 보고에 첨부만 한다.

---

## 7. 배포 절차 (디렉터 전용)

1. 정적 게이트 + 삼각형 수 확인
2. 턴테이블 렌더 육안 검수
3. `_incoming/`으로 전송 → 압축 해제 → md5 대조
4. Unity에서 임포트 확인: **Scale Factor 1 / Convert Units 꺼짐 / Generate Colliders 꺼짐**
5. 재컴파일 에러 0 확인
6. 커밋

`.meta`는 Unity가 첫 임포트에 만든다. 노말맵만 디렉터가 미리 써 준다(`textureType: 1`).
guid는 새로 만들 때마다 저장소 전체와 충돌 검사를 한다.

---

## 8. 절대 하지 말 것 (요약)

1. 런타임 자식 회전으로 축 맞추기 → 전단
2. 원점을 바운딩 박스 중심에 두기 → 접지 실패
3. Unity 머티리얼 에셋 만들기 → 런타임 코드가 담당
4. `Generate Colliders` 켜기 → 게임플레이 치수와 어긋남
5. `Resources.Load`를 **MonoBehaviour 필드 초기자에서** 호출 → 생성자에서 금지되어 null,
   그 null을 캐시하면 세션 내내 에셋이 죽는다(실제 사고)
6. 프로브 실패를 영구 캐시하기
7. 렌더 검수 없이 배포하기
