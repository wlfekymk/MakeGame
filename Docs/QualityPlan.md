# 퀄리티 향상 계획 — 외부 레퍼런스 · 오픈소스 · 무료 에셋

> 작성 2026-08-20 (0.2.56 기준). 디렉터 지시: "외부 레퍼런스·오픈소스·무료 에셋을 찾아서
> 게임 퀄리티를 높이는 일을 중점으로."
>
> **이 문서는 실행 순서를 정하는 표다.** 항목을 고르면 그때부터 웨이브로 진행한다.

---

## 0. 먼저 알아야 할 제약 — 이것이 목록의 모양을 정한다

**나는 웹에서 파일을 내려받을 수 없다.** 검색과 문서 읽기(WebFetch)는 되지만
`curl`/`wget`/파이썬 fetch는 전부 금지다. 그래서 모든 항목은 셋 중 하나다:

| 구분 | 뜻 | 진행 방식 |
|---|---|---|
| **[자립]** | 에셋 없이 코드·절차 생성만으로 끝난다 | 내가 혼자 끝낸다. 지시만 주면 된다 |
| **[투하]** | 디렉터가 파일을 받아 폴더에 넣어야 한다 | 내가 **정확한 다운로드 목록과 넣을 경로**를 만들고, 파일이 들어오면 배선·임포트 설정·`.meta`까지 처리 |
| **[학습]** | 오픈소스를 **읽고 기법만** 우리 코드에 옮긴다 | 내가 혼자 끝낸다. 파일은 안 가져온다 |

**현재 에셋 실측** (0.2.56): PNG 69장(아이템 아이콘 31 · 절차 텍스처 23 · 기타 15) ·
MP3 1개(BGM) · OBJ 150개(Blender 생성) · 커스텀 셰이더 8개 · 머티리얼 4개 · 프리팹 3개.
**즉 이 게임은 거의 전부 절차 생성물이다.** 텍스처는 알베도만 있고 노멀·러프니스가 없으며,
생물은 전부 프리미티브 조합이고 **골격 애니메이션이 하나도 없다.**

## 2. [자립] — 지금 당장 나 혼자 할 수 있는 것

### A1. URP 포스트프로세싱 볼륨 정비 ★가장 먼저
현재 `ColorAdjustments`(대비·채도) 하나만 쓰고 있다. URP에 이미 들어 있는 나머지를
쓰지 않는 것은 **공짜로 놓고 있는 퀄리티**다.

- **Bloom** — 해수면 반사·모닥불·번개가 즉시 "빛나 보인다". 무인도 물놀이 톤의 핵심
- **Tonemapping (ACES 또는 Neutral)** — 지금은 하이라이트가 그냥 흰색으로 뭉갠다
- **Vignette + Chromatic Aberration** — 잠수 중·체력 위급 시에만 강도를 올려 **상태를 화면으로 알린다**
- **Depth of Field** — 인벤토리·전체 지도를 열면 배경을 흐린다(창이 떠 보인다)
- **Motion Blur** — 뗏목 항해와 회피 구르기에만
- **SSAO** — 야자수 밑동·건축물 접지가 붕 떠 보이는 문제를 바로잡는다

> 이미 `WeatherSystem`·`DayNightCycle`이 볼륨을 만지고 있어 붙일 자리가 있다.
> 시간대·날씨·수중·상태이상마다 프로파일을 보간하면 **에셋 0장으로 화면이 달라진다.**

### A2. 절차 텍스처에 노멀·러프니스 맵 추가
지금 PIL로 만드는 7종(`noise`/`wood`/`stone`/`leaf`/`metal`/`sand`/`water`)은 **알베도뿐**이다.
표면이 전부 매트한 종이처럼 보이는 직접적인 원인이다.

- 같은 파이썬 파이프라인에서 **높이맵 → 노멀맵(Sobel)** 을 생성한다. 새 의존성 0
- 러프니스/메탈릭도 절차 생성(젖은 모래는 낮은 러프니스, 바위는 높음)
- URP Lit의 `_BumpMap`/`_MetallicGlossMap`에 연결
- 비 오는 동안 젖음(러프니스 하강)을 **머티리얼 파라미터로** 전환하면 비의 체감이 크게 오른다

### A3. 지형 머티리얼 스플랫 + 삼중 평면 매핑
`IslandMeshGenerator`가 정점 색으로만 모래/풀/암반을 구분한다. 경사면에서 텍스처가 늘어나고
경계가 뭉갠다. 커스텀 셰이더 하나로 **삼중 평면(triplanar) + 높이·경사 기반 블렌딩**을 넣으면
같은 지형 메시가 완전히 달라 보인다. (B5의 PBR 텍스처가 들어오면 효과가 배가된다.)

### A4. 카메라·연출
피격 시 화면 흔들림, 달릴 때·항해 속도에 따른 FOV 변화, 창 열고 닫을 때 짧은 전환,
잠수 진입 시 시야 왜곡. 전부 코드만으로 되고, "손맛"이 붙는다.

## 3. [투하] — 디렉터가 파일을 넣어주면 내가 배선한다

### B1. 골격 애니메이션 생물 — 이 게임의 가장 큰 약점
**지금 생물은 전부 프리미티브 조합이고 애니메이션이 절차 회전뿐이다.** 상어도 곰도 나무토막이
움직이는 것처럼 보인다. 여기를 고치면 "프로토타입"에서 "게임"으로 넘어간다.

- **Quaternius — Ultimate Animated Animal Pack** (CC0, 저작자 표시 불필요, 상업 사용 자유)
  - 12종 이상, 각각 **12개 이상 애니메이션**(공격/사망/걷기/달리기/점프…), FBX·Blend·glTF
  - 우리에게 바로 맞는 것: 곰 · 상어(별도 해양 팩) · 게 · 새 · 사슴류(사냥감)
  - `Universal Animation Library`(같은 저자, CC0)에 **사람 애니메이션**도 있다 — 플레이어 손·도구 사용
- 내가 할 일: Animator 컨트롤러 구성, 기존 `CreatureVisualBuilder`/`CreatureMotion`과의 교체 배선,
  `HazardSource`/`BossCreature` 연결, 프리팹화, LOD
- **위험**: 프리미티브 경로를 지우지 말고 **폴백으로 남긴다**(모델이 없는 종은 기존 방식 유지).
  보스 3종은 크기가 특수해서 스케일 보정이 필요하다.

### B2. 한글 폰트 교체 — 가장 싼 큰 변화
지금 `LegacyRuntime.ttf` 하나뿐이라 **위계를 크기로만** 만들고 있다(ArtDirection 4.3).

- **Pretendard** (SIL Open Font License, 상업 사용·임베딩 자유) — 굵기 9종
- 굵기가 생기면 제목/본문/캡션이 크기 말고 **무게**로 갈린다. UI 전체가 즉시 정돈된다
- 내가 할 일: `UIBuilder.CreateText` 한 곳만 고치면 전 UI에 적용된다(이미 초크포인트로 모아뒀다)
- **TextMeshPro 전환은 별건이다** — 지금은 레거시 `Text`라 굵기별 폰트 에셋을 직접 지정하는
  방식으로 간다. TMP는 외곽선·그림자·SDF가 붙지만 15,204줄 UI 반환형이 바뀌어 별도 웨이브다

### B3. 실제 사운드
**MP3가 딱 1개**(BGM)고 나머지는 전부 `ProceduralAudioClipGenerator`가 합성한다. 삐- 소리가
게임 전체 몰입을 깎는다.

- **Freesound.org의 CC0 필터** — 파도·바람·비·새·발소리·나무 베기·물속
- **Kenney 오디오 팩** (CC0) — UI 클릭, 임팩트, 인터페이스
- 우선순위: ① 파도·바람(상시 들린다) ② 발소리(표면별) ③ 채집·타격 ④ UI
- 내가 할 일: `AudioManager` 배선, 표면별 발소리 판정, 거리 감쇠, 절차 생성은 폴백으로 유지

### B4. 아이템 아이콘 12종
`DECISION_LOG` C2에 남아 있는 빚. 신규 아이템 12종이 아이콘 없이 **카테고리색 + 첫 글자**로 뜬다.

- **Kenney Game Icons** (CC0) 또는 **game-icons.net** (CC BY 3.0 — **저작자 표시 필요**,
  크레딧 화면에 한 줄 넣으면 된다)
- 기존 31개가 SVG→PNG 제작이라 **스타일이 튀지 않게 색·굵기를 맞추는 후처리**를 내가 한다

### B5. PBR 텍스처
- **ambientCG** (CC0) · **Poly Haven** (CC0) — 둘 다 저작자 표시 불필요
- 필요한 것: 모래 2종(마른/젖은) · 바위 · 나무껍질 · 나뭇잎 · 금속 · 천 · 물 노멀
- A2(절차 노멀)와 **경쟁이 아니라 보완**이다: 절차는 무한 변주에 좋고 실측 PBR은 근접 품질에 좋다.
  근접에 자주 보이는 것(모래·바위·나무)만 실측으로 바꾸는 게 비용 대비 최선

### B6. HDRI 하늘
지금 스카이박스는 절차 그라디언트다. **Poly Haven HDRI** (CC0) 몇 장이면 새벽/한낮/노을/폭풍의
하늘과 **환경광 색**이 통째로 달라진다. `DayNightCycle`이 이미 스카이박스를 만지고 있어 붙이기 쉽다.

## 4. [학습] — 오픈소스를 읽고 기법만 옮긴다

### C1. 바다 — Unity 공식 `boat-attack-water` 검토 ⚠️위험 높음
- **Unity Technologies/boat-attack-water** — Unity Companion License (Unity 프로젝트에서 상업 사용 가능),
  UPM git URL로 설치 가능. Boat Attack 데모의 실제 물 시스템이다
- 매력: 파도 시뮬레이션·부력·수면 아래 렌더링이 검증된 상태로 들어온다
- **그런데 우리 바다는 이미 8개 셰이더가 얽혀 있다** — `MGOcean` · `MGShoreline` · `MGShoreBreak` ·
  `MGCaustics` · `MGKelpSway` + `ShorelineRibbon`·`OceanWaves`·`RaftSailing`의 부력.
  통째로 갈아끼우면 최근 몇 웨이브에서 만든 해안 파도·뗏목 항해가 전부 다시 붙어야 한다
- **권고: 도입이 아니라 학습.** 그쪽의 Gerstner 파도 합성·수면 아래 산란 기법만 읽어
  `MGOcean`에 이식한다. 전면 교체는 다른 항목을 다 끝낸 뒤에 별도로 판단

### C2. 풀 GPU 인스턴싱 개선
`MGGrass` + `GrassFieldDriver`가 이미 있다. 공개된 구현들(`MangoButtermilch/Unity-Grass-Instancer`의
절두체·오클루전 컬링, Cyanilux의 인스턴싱 분해 글)을 읽고 **밀도와 시야 거리를 올리는 방법**만
가져온다. 파일은 안 가져온다.

## 5. 제안하는 실행 순서

1. **1웨이브 — A1 + A4** (에셋 0장). 포스트프로세싱과 카메라 연출만으로 첫인상이 바뀐다.
   여기서 "얼마나 달라지는가"를 보고 다음 투자를 정한다
2. **2웨이브 — B2 폰트 + B4 아이콘** (작은 다운로드 2건). UI가 정돈된다
3. **3웨이브 — A2 절차 노멀맵** (에셋 0장). 표면이 입체로 보이기 시작한다
4. **4웨이브 — B3 사운드**. 몰입도 대비 비용이 가장 좋다
5. **5웨이브 — B1 골격 애니메이션 생물**. 가장 크고 가장 오래 걸린다. 앞의 넷이 끝난 뒤에
6. 그 다음 — B5/B6/A3(지형 셰이더), 마지막에 C1 판단

## 6. 라이선스 정리 — 넣기 전에 확인할 것

| 출처 | 라이선스 | 저작자 표시 | 상업 |
|---|---|---|---|
| Kenney | CC0 | 불필요 | 가능 |
| Quaternius | CC0 | 불필요 | 가능 |
| ambientCG | CC0 | 불필요 | 가능 |
| Poly Haven | CC0 | 불필요 | 가능 |
| Freesound (**CC0 필터 적용 시**) | CC0 | 불필요 | 가능 |
| game-icons.net | CC BY 3.0 | **필요** | 가능 |
| Pretendard | SIL OFL | 불필요(폰트 이름 규정 있음) | 가능 |
| Unity boat-attack-water | Unity Companion | 불필요 | 가능(Unity 프로젝트 한정) |

**규칙 (2026-08-20 디렉터 지시로 완화)**: **LICENSE 파일이 없다는 것만으로는 멈추지 않는다.**
참고하고 우리 코드로 다시 구현하는 것은 진행한다.

다만 두 가지는 계속 지킨다 — 규율이 아니라 실무상 필요해서다:
1. **출처를 `Docs/Attribution.md`에 남긴다.** 무엇을 어디서 참고했는지 기록이 없으면
   나중에 문제가 생겼을 때 **무엇을 빼야 하는지조차 모른다.** 스팀 출시 전 점검용이다.
2. **원본 파일을 그대로 복사해 넣는 것과 다시 구현하는 것은 구분해 기록한다.**
   전자는 지울 때 통째로 지우면 되고, 후자는 지울 필요가 없다.

> 참고: **나는 웹에서 파일을 내려받을 수 없다**(환경 제약, 라이선스와 무관).
> 그래서 외부 소스는 언제나 "읽고 다시 구현" 경로로만 들어온다. 원본 파일이 필요하면
> 디렉터가 받아서 폴더에 넣어야 한다 — 이 문서 0절의 **[투하]** 가 그 뜻이다.

`Docs/Attribution.md`를 만들어 CC BY 항목을 모으고, 게임 크레딧 화면에도 같은 내용을 넣는다.

## 7. 이 목록에 **일부러 넣지 않은 것**

- **Unity Asset Store 유료 에셋** — 지시가 "무료"였다
- **AI 생성 에셋** — 스팀 출시 시 생성형 AI 사용 고지 의무가 걸리고, 라이선스 근거가 약하다
- **TextMeshPro 전면 전환** — B2와 묶으면 웨이브가 터진다. 폰트 교체 효과를 먼저 보고 별도 판단
- **바다 전면 교체(C1 도입)** — 위험 대비 이득이 지금은 나쁘다. 학습만
- **공략서 갱신** — 동결됐다(`DECISION_LOG` C0-b)
